## 教学说明

**学习目标**

1. 能根据要说明的问题（比较、趋势、构成、分布、关系、地区、转化）选择合适的图表（应用）；
2. 能说出换成不合适的图表会丢掉什么信息（理解）；
3. 能识别纵轴截断、气泡按半径画、饼图类别太多等误导性图表，并说明怎样改正（评价）。

**画面与操作**

- “选图表”：点一个目的，显示推荐的图和适用场合；点“不合适的图”，显示一个常见的错误选择，并解释为什么不合适。
- “找误导”：四个案例（柱状图纵轴不从 0 开始、折线图的纵轴、气泡按半径画、饼图类别太多），每个案例在两种画法之间切换，比较给人的印象。

**数据来源**：小象优选 9 月已完成订单的统计结果（实验 12-1 的 5 张小表；订单金额分布按 100 元一档统计）。

**课堂用法建议**

1. 先不看推荐，给出“各品类销售额”“每日销售额”“支付方式占比”三个问题，让学生说出各用什么图，再用动画核对。
2. 在“找误导”的第 1 个案例中，先只展示“纵轴从 430 开始”的画法，问学生“28 日是 25 日的几倍”，再切换到从 0 开始，引出柱状图纵轴必须从 0 开始。
3. 对比第 1、2 个案例，讨论为什么折线图的纵轴可以不从 0 开始。
4. 课后让学生在新闻或广告中找一张误导性图表，说明错在哪里。

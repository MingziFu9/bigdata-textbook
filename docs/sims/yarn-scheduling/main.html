YARN 资源分配：作业怎样分到“内存格子”

集群里每台 NodeManager 的内存被切成一个个容器（Container）。ResourceManager 先给作业分一个容器跑 ApplicationMaster，再由它申请容器跑 Map 和 Reduce 任务。按“下一步”逐秒播放。

ResourceManager：作业列表（和 8088 网页上的 Applications 页对应）

NodeManager：每台机器的内存使用 AM 作业 A 任务 作业 B 任务 （斜纹 = Reduce）

发生了什么

    简化说明：每个 Map 任务运行 3 秒、每个 Reduce 任务运行 2 秒，Map 全部结束后才开始 Reduce；同一队列里先提交的作业优先分配（先来先服务）；所有 AM 合计最多占集群内存的 10%（容量调度器的默认值），但第一个作业总能启动；只按内存分配。真实集群里任务时间各不相同，Reduce 也可以在 Map 快结束时提前启动。

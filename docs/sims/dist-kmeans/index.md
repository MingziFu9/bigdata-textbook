## 教学说明

**学习目标**

1. 能说出 K-Means 每一轮的两步：把每个点分给最近的中心、把中心移到本群的平均位置（理解）；
2. 能说明在 Spark 上运行时，节点之间传的是“每群的人数和坐标之和”而不是原始数据（理解）；
3. 能通过更换初始中心和 k，说明为什么要固定 seed、为什么 k 要结合业务来选（应用）。

**画面与操作**

- 选 k（2、3、4），按“下一步”逐步推进，每轮分三步：广播中心 → 各节点分配并求和 → Driver 汇总、更新中心；也可以按“一直跑到收敛”。
- ① 圆点、方块、三角分别是 3 个节点上的数据，颜色是所属的群，✚ 是中心，虚线箭头是中心这一轮移动的方向。
- ② 3 个节点各自的“人数、x 之和、y 之和”，以及 Driver 的合计；新中心 = 合计的坐标之和 ÷ 合计人数。

**数据来源**：示意数据，48 个点由固定随机种子生成，分成“最近常买的高消费”“最近买过的普通用户”“很久没来的”三团，按顺序轮流放到 3 个节点上。收敛的判断是中心最多移动不到 0.01。

**课堂用法建议**

1. k = 3，逐步推进第 1 轮，让学生先猜每个点会变成什么颜色，再看节点表格验证“合计 ÷ 人数 = 新中心”。
2. 按“换一组初始中心”几次，比较收敛需要的轮数和最终分群是否一样，引出 `seed` 参数。
3. 讨论：节点 1 上传给 Driver 的是几个数？如果每个节点有 1000 万个用户，这个数会变吗？

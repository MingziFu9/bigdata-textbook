点一个容器，看它运行哪些进程、开了哪些端口、数据存在哪里；点上方的端口，看浏览器访问它时连到了哪个容器。下面的按钮可以模拟加节点和停节点。
你的电脑（宿主机）：Docker Desktop 或 Docker Engine浏览器访问 localhost 的这些端口 ↓
Docker 网络 bigdata_default：容器之间用名字互相访问（master、worker1……）
共享目录：宿主机的 labs/ 挂载到每个容器的 /labs；配置文件从 labs/cluster/conf/ 挂载到 /opt/hadoop/etc/hadoop/

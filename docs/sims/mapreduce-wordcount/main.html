Map 端

⇩ Shuffle：每个 Reducer 到所有 Map 那里拉取属于自己分区（同一颜色）的数据 ⇩

Reduce 端

计数器（和 Hadoop 作业结束时打印的计数器同名）

颜色表示分区：同一种颜色的键值对会被送到同一个 Reducer。分区号 = 键的哈希值 ÷ Reducer 个数的余数，算法与 Hadoop 默认的 HashPartitioner 相同，所以这里的结果和在真实集群上运行完全一致。
